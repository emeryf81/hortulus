# Mischkultur

Manche Pflanzen helfen einander, andere stehen sich im Weg. Mischkultur ist zum Teil Wissenschaft und zum Teil Gärtnererfahrung, deshalb zeigt Hortulus immer, **warum** eine Kombination gut oder schlecht abschneidet.

## So bewertet Hortulus

Der Planer betrachtet Pflanzen innerhalb des **Einflussradius** (standardmäßig 60 cm) und gewichtet:

1. **Bekannte Paare** aus der Pflanzendatenbank (Tomate + Basilikum: gut; Kartoffel + Tomate: schlecht, sie teilen sich die Kraut- und Braunfäule).
2. **Familienbeziehungen**, wenn es keine besondere Regel gibt (Lauchgewächse neben Hülsenfrüchtlern bremsen die Bohnen).
3. **Schädlingsabwehr**: eine Pflanze, die den Schädling eines Nachbarn vertreibt (Schnittlauch gegen die Möhrenfliege, Studentenblume gegen Nematoden) oder ihn als Fangpflanze weglockt (Kapuzinerkresse für Blattläuse).
4. **Allelopathie**: Pflanzen, deren Wurzelausscheidungen Nachbarn hemmen (Fenchel, Wermut, Sonnenblume).
5. **Konkurrenz**: Zwei Starkzehrer dicht beieinander teilen sich dieselben Nährstoffe.
6. **Schatten**: Eine hohe Kultur auf der Sonnenseite einer niedrigen nimmt ihr das Licht - es sei denn, die niedrige Kultur verträgt Schatten (Salat mag ihn im Sommer sogar).

Der Abstand zählt: Je näher, desto stärker die Wirkung. Bei Konflikten schlägt Hortulus **bessere Nachbarn** vor.

## Klassische gute Paare

| Paar | Warum |
|---|---|
| Möhre + Zwiebel/Lauch | Die Gerüche verwirren Möhrenfliege und Zwiebelfliege |
| Tomate + Basilikum | Basilikum vertreibt die Weiße Fliege; ähnliche Ansprüche |
| Zuckermais + Stangenbohne + Kürbis („Drei Schwestern“) | Stütze, Stickstoff und Bodendeckung |
| Kohl + Sellerie oder Dill | Verwirrende Gerüche gegen den Kohlweißling |
| Bohnen + Bohnenkraut | Vertreibt die Schwarze Bohnenlaus |
| Studentenblume überall | Nematoden, lockt Schwebfliegen an |

## Vermeiden

| Paar | Warum |
|---|---|
| Kartoffel + Tomate | Dieselbe Krankheit (Kraut- und Braunfäule) |
| Zwiebel/Knoblauch + Bohnen/Erbsen | Hemmen Hülsenfrüchtler |
| Fenchel + fast alles | Allelopathisch |
| Kohl + Erdbeere | Konkurrenz, Schädlinge |

Mischkultur ersetzt weder Fruchtfolge noch gute Bodenpflege, sie erhöht aber die Artenvielfalt: Mehr Blüten und Düfte bedeuten mehr Nützlinge.
