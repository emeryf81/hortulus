# Werkzeug und Material

Gutes Werkzeug muss nicht teuer sein, aber solide und scharf. Kaufen Sie lieber einen guten Spaten als drei schlechte. In der Aufgabenliste zeigt Hortulus, welches Werkzeug und Material jede Arbeit braucht; die **Einkaufsliste** (Empfehlungen › Zubehör) berechnet, was in dieser Saison zu kaufen ist.

## Die Grundausstattung

| Werkzeug | Wofür | Tipp |
|---|---|---|
| Grabegabel / Grelinette | Boden lockern, ohne ihn umzudrehen | schont Rücken und Bodenleben |
| Spaten | Pflanzlöcher, Rasenkanten | mit einer Feile scharf halten |
| Hacke (Zieh- oder Schuffelhacke) | Jäten, Kruste aufbrechen | bei Trockenheit wöchentlich |
| Rechen | feines Saatbeet, Mulch verteilen | |
| Pflanzkelle und Pflanzholz | Auspflanzen, Lauch und Zwiebeln | |
| Gartenschere (Bypass) | Schneiden, Ernten | zwischen den Pflanzen desinfizieren |
| Gießkanne mit feiner Brause + Schlauch mit Brause | Säen und Gießen | Regenwasser verwenden |
| Schubkarre oder Gartenwagen | Kompost, Mulch, Ernte | |
| Pflanzschilder und Bleistift | wissen, was wo steht | Bleistift bleibt lesbar |
| Gartenschnur / Jute | Anbinden | |
| Anzuchtschalen, Töpfe, Anzuchterde | Vorziehen drinnen | |
| Handschuhe, Kniekissen | | |

## Praktisch für Begeisterte

- **Bodenthermometer** - erst säen, wenn der Boden warm genug ist.
- **Min/Max-Thermometer** im Gewächshaus.
- **Bodenfeuchtemesser** oder Funksensor (lässt sich mit Home Assistant verbinden).
- **Saatbrett / Pflanzschnur** für gerade Reihen, **Reihenzieher**.
- **Pflanzenlampe und Heizmatte** zum Vorziehen.
- **Astschere und Baumsäge** für Obstbäume; **Dreibeinleiter** zum Pflücken.
- **Perlschlauch und Timer** (oder Bewässerung über Home Assistant).
- **Kompostsieb** und ein **Kompostthermometer**.

## Material pro Saison

| Material | Wann | Wie viel (Faustregel) |
|---|---|---|
| Kompost | Frühjahr und Herbst | 3-5 l/m² pro Jahr (etwa 2-3 kg) |
| Organischer Dünger (Pellets) | für Starkzehrer | 50-100 g/m² |
| Kalk (Dolomit) | alle 3 Jahre bei pH < 6 | 100-200 g/m², nie zusammen mit Mist |
| Vlies (17-30 g/m²) | Frost, Frühkulturen, Insekten | Beetbreite + 50 cm |
| Kulturschutznetz (0,8 mm) | Kohl, Möhren, Zwiebeln | Beetbreite + 60 cm |
| Schattiernetz 30-40 % oder Schattierfarbe | Gewächshaus, Salate bei Hitze | Dachfläche |
| Stroh oder Rasenschnitt | Mulch | 5-8 cm Schicht |
| Bambusstäbe, Tomatenspiralstäbe | Bohnen, Tomaten | 1 pro Pflanze |
| Vogelschutznetz | Obst, junge Kohlpflanzen | feinmaschig |
| Gründüngungssaatgut | Herbst | 2-3 g/m² (Phacelia), 15-20 g/m² (Roggen) |

## Dünger und Mittel selbst herstellen

| Was | Rezept | Anwendung |
|---|---|---|
| Brennnesseljauche (Stickstoff) | 1 kg junge Brennnesseln in 10 l Regenwasser, 10-14 Tage gären lassen | 1:10 für Blattgemüse, 1:20 für Sämlinge |
| Beinwelljauche (Kalium) | 1 kg Blätter in 10 l Wasser, 3 Wochen | 1:10 für Tomate, Zucchini, Obst |
| Komposttee | eine Schaufel reifer Kompost in einem Jutesack, 3 Tage in einer Tonne Regenwasser | unverdünnt gießen |
| Holzasche (Kalium, Kalk) | Asche von unbehandeltem Holz | 50-100 g/m², nicht für Kartoffeln (Schorf) |
| Kaffeesatz | ausgebreitet, getrocknet | leicht sauer, für Heidelbeeren; Regenwürmer lieben ihn |
| Eierschalen | getrocknet und gemahlen | Kalk, rund um Kohl; grob gegen Schnecken |
| Urin (verdünnt) | 1:10 mit Wasser, frisch | reich an Stickstoff, auf den Boden, nicht auf die Blätter |
| Rasenschnitt | dünne Schichten | Mulch und langsamer Stickstoff |
| Laubkompost | 1-2 Jahre verrottetes Laub | Anzuchterde, Bodenverbesserer |

## Werkzeugpflege

Nach jedem Gebrauch: Erde abbürsten und trocknen. Einmal im Jahr (November): schärfen, Rost mit Stahlwolle entfernen, das Metall leicht ölen und Holzstiele mit Leinöl einreiben. Die Gartenschere zwischen kranken Pflanzen mit Alkohol desinfizieren.
